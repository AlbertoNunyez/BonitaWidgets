Date Range Picker Widget

A comprehensive widget for selecting date ranges with an intuitive interface and additional features like quick selection buttons and validation.

Overview

The Date Range Picker widget allows users to select a start and end date using native HTML5 date inputs, providing a consistent experience across different browsers and devices. It includes validation, formatting options, and convenient quick selection buttons.

Properties

Property Type Description Default
startDate Variable Variable to store the selected start date (YYYY-MM-DD format) -
endDate Variable Variable to store the selected end date (YYYY-MM-DD format) -
dateFormat Choice Display format for dates: yyyy-MM-dd, dd/MM/yyyy, MM/dd/yyyy, dd-MM-yyyy yyyy-MM-dd
placeholder Text Placeholder text when no date is selected "Select date range"
minDate Text Minimum selectable date (YYYY-MM-DD format) -
maxDate Text Maximum selectable date (YYYY-MM-DD format) -
required Boolean Make the date range selection mandatory false
disabled Boolean Disable the date range picker false
cssClasses Text Additional CSS classes to apply to the widget -

Features

  • Native Date Inputs: Uses HTML5 date inputs for consistent browser experience
  • Date Validation: Automatically ensures start date is before end date
  • Multiple Formats: Support for various date display formats
  • Quick Selection: Buttons for common date ranges (Last 7 days, Last 30 days, etc.)
  • Duration Display: Shows the number of days in the selected range
  • Clear Function: Easy way to clear both dates
  • Responsive Design: Adapts to different screen sizes
  • Accessibility: Proper ARIA labels and keyboard navigation

Usage Examples

Basic Setup

1. Create two variables in your form: startDateVar and endDateVar

2. Add the Date Range Picker widget to your form

3. Bind the Start Date property to startDateVar

4. Bind the End Date property to endDateVar

With Validation

Set the required property to true and optionally set minDate and maxDate to restrict the selectable date range.

Example: minDate: "2023-01-01", maxDate: "2024-12-31"

Custom Styling

Use the cssClasses property to add custom CSS classes:

cssClasses: "my-custom-date-picker compact-layout"

Data Binding

The widget stores dates in ISO format (YYYY-MM-DD) in the bound variables, making them easy to use with:

  • REST API calls
  • Database queries
  • Business data variables
  • Process variables

Browser Compatibility

This widget uses HTML5 date inputs and is compatible with:

  • Chrome 20+
  • Firefox 57+
  • Safari 14.1+
  • Edge 12+

Note: For older browsers, the date inputs will fall back to text inputs.

Customization

The widget can be customized using CSS. Key classes:

  • .date-range-picker-widget - Main container
  • .date-range-container - Input container
  • .date-input-wrapper - Individual date input wrapper
  • .date-range-display - Selected range display
  • .quick-select-buttons - Quick selection buttons container
